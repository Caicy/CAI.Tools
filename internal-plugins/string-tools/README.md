# 字符串处理

CAI.Tools 内置的离线文本工作台，无额外依赖，不保存输入历史。

## 使用

重启开发实例后，在搜索框输入“字符串处理”或“SQL IN”。首次进入自动读取剪贴板；后续进入保留当前草稿，可用“读取剪贴板”主动替换。

采用紧凑横向工具栏，原文与结果并排，复制按钮位于结果区域。SQL 值类型与 Unicode 方向可直接点击分段按钮；行整理的关键词筛选、查找替换的高级选项默认折叠。支持系统明暗主题。

### 按文本内容推荐

- 至少两行非空文本：同时推荐“SQL IN 拼接”和“行整理”；单行尾部换行不算多行。
- Tab 分隔多个非空单元格：推荐“SQL IN 拼接”。
- 由英文、数字、常见 ASCII 符号组成且含英文字母：推荐“大小写与命名”；纯数字、混合中文等不触发。
- 含有效 `\uXXXX`、UTF-16 代理对、`\u{...}` 或 `U+....`：推荐“Unicode 解码”，可嵌在普通文本内；路径和错误转义不按有效 Unicode 推荐。
- 多条规则可同时命中，字符串工具之间按 Unicode 解码、SQL IN、行整理、大小写与命名排列。该顺序只调整本插件的匹配项，不改变其他插件的位置；手动搜索入口保持原有规则。
- 主搜索框文本匹配与超级面板使用同一组规则；点击后使用本次完整原文并直达对应工具，Unicode 解码明确切回解码方向。
- 通用“字符串处理”入口保留；自定义拼接、查找替换继续支持手动搜索，本次不增加自动推荐。

推荐只提供工具入口，不会自动改写或复制原文。新文本匹配入口替换当前草稿；普通手动重入仍保留草稿。

- SQL IN 拼接：每行或每个制表符单元格为一项，默认去空行、首尾空格和重复项。自动识别每个值，文本加单引号，普通十进制数直接拼接；可选全部文本、全部数字以及带括号输出。
- 大小写与命名：小写、大写、大驼峰、小驼峰、下划线、短横线。每行独立转换，支持已有驼峰和英文缩写边界。
- Unicode：支持 `\u4e2d\u6587`、UTF-16 代理对、`\u{1F600}` 和 `U+4E2D`；反向转换只转义非 ASCII 字符，保留英文及排版。错误转义会清除结果并禁止复制。
- 行整理：忽略空行，可选去首尾空格与去重，默认保持原顺序和大小写。
- 自定义拼接：输入支持换行、逗号、分号、Tab 或自定义字面分隔符。输出分隔符可留空，支持 `\n`、`\r`、`\t`、`\\` 排版转义；未知转义保持原文。每项前后缀按原文添加，不解释转义。默认去空项和首尾空格，去重可选；空输入不产生前后缀。
- 查找替换：普通模式的查找与替换内容均按字面处理；正则模式支持 `$1`、`$2`、`$&` 等 JavaScript 替换语法，表达式不用 `/` 包裹。可选全部／首次、忽略大小写、多行锚点 `^` / `$`；空查找不改变原文，空替换删除匹配内容。正则出错或执行超过 1 秒会清空输出并禁用复制，可继续修改输入恢复预览。
- 行排序与筛选：在清理后按关键词字面匹配，保留或排除包含关键词的行，支持筛选忽略大小写。排序支持原顺序、文本字符顺序、普通十进制数值和自然排序（`item2` 在 `item10` 前），最后可倒序。数字排序不经过浮点数，长 ID 和小数保留精度；含非数字行时报错，可先筛选再排序。空关键词不筛选。

输入后实时预览，“复制结果”或 Ctrl/Cmd+Enter 复制。切换页签保留原文和选项；清空同时清空输入与输出。

新增搜索入口：“自定义拼接”“分隔符转换”“查找替换”“正则替换”“行排序”“行筛选”。“多行转逗号”继续进入原 SQL IN 工具；需要无引号的值列表可使用自定义拼接。

## SQL 细节

`00123` 等有前导零的编号按文本保留，长数字 ID 不经过 JavaScript Number。选择全部数字时，前导零编号与非普通十进制值会报错。

文本单引号按 SQL 标准重复转义，如 `O'Reilly` → `'O''Reilly'`。输入含反斜杠会提示数据库模式差异；使用前应确认目标数据库的字符串转义设置。列表为空时不输出无效的 `()`。本工具只生成值列表，不执行 SQL。

## 开发

静态资源在 `public/`，宿主开发启动直接加载；正式制品沿用 `build/afterPack.js` 复制资源，不需要独立 Vite 服务。

- 转换与接入测试：`pnpm exec vitest run tests/main/stringTools.test.ts tests/main/internalPlugins.test.ts tests/main/pluginDevelopmentRegistry.test.ts`
- 源码 Electron E2E：`pnpm test:e2e`；专项可使用 `pnpm test:e2e tests/e2e/string-tools.spec.ts`。
- E2E 使用临时数据与旧数据目录，截图来自插件 WebContentsView，输出到 `test-results/playwright`。
